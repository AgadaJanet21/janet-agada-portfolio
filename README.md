# Janet Agada — Product Manager Portfolio

Personal portfolio site. Built with TanStack Start (React) + Tailwind CSS + shadcn/ui.

## Run locally
```bash
npm install
npm run dev
```
The dev server URL is printed in the terminal.

## Build
```bash
npm run build
```

## Deploy
This is a standard Node/Vite app and deploys cleanly to Vercel, Netlify, or any Node host. Point your host at this repo and use `npm run build`.

## Structure
- `src/routes/` — pages (`index.tsx` home, `work.confette.tsx`, `work.glown.tsx` case studies)
- `src/components/` — layout + case-study components
- `src/components/ui/` — shadcn/ui primitives
