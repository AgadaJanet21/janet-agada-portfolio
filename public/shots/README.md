# Product screenshots

These images appear on the case-study pages. Save PNGs (or JPGs — but keep the
`.png` names below) into this folder with these EXACT names:

| Save as | Which screenshot |
|---|---|
| `glown-overview.png` | Glown business dashboard ("Good morning…" — appointments, revenue today, this-month revenue/bookings/new clients) |
| `glown-reviews.png`  | Glown Reviews page (client reviews with star ratings) |
| `glown-marketing.png`| Glown Marketing page (client segments: Slipping away, Best clients, Repeat no-shows…) |
| `glown-messages.png` | Glown Message log (SMS / WhatsApp rows with Delivered / Sent status) |
| `glown-payroll.png`  | Glown Payroll (monthly table: Total Gross / Deductions / Total / Status) |
| `confette-admin.png` | Confette Admin Dashboard (Total Events / Live Events / Total Bids / Vendors) |
| `confette-budget.png`| Confette budget breakdown (an event's budget split across categories with bars) |
| `confette-events.png`| Confette All Events list (rows with budgets and Draft / Open / Bidding statuses) |

Any file not present is simply hidden on the site, so you can add them one at a time.
Tip: crop out the browser chrome/URL bar for a cleaner look.
